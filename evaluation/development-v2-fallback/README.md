# Hybrid V2 fallback development corpus (superseded)

SUPERSEDED FOR MODEL QUALITY EVALUATION.

This historical development-only corpus remains preserved for provenance. Its
requests were produced from a small set of repeated templates with artificial
numeric suffixes such as `(example N)`. Those suffixes defeated the old
normalization check and overstated linguistic diversity. Use
`evaluation/development-v2-fallback-v2/` for future fallback-language work.
