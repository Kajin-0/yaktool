# Production-derived fallback set

`model-fallback-development.jsonl` is historical and **SUPERSEDED**: it was
generated from stale pre-production routing and must not be resumed.

`routing-development-v2.jsonl` and `model-fallback-development-v2.jsonl` are
generated by the Rust `route_without_model` helper from the 600-case development
corpus. The current partition is 87 hard-deny, 355 RuleInterpreter, 100
read-only, 0 move-frame (all move requests are handled by the existing exact
RuleInterpreter grammar), and 58 model fallback candidates.

No model inference is performed by this artifact generation.
