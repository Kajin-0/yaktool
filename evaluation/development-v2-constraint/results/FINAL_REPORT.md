# Hybrid V2 constraint-rich development evaluation

The four frozen ablations were run on the 400-case constraint corpus. B (structured slot instruction) was the highest exact result (36.50%) while all variants retained zero unsafe and wrong-slot accepted mutations. The 600-case regression used the same B settings and produced 59.17% exact accuracy, 100% observed mutation precision (181/181 accepted moves), and 28.00% read-only exact accuracy. These are development results only; no holdout-v2 was created.
